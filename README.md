# Personal AI Assistant

A personal AI assistant built with n8n, Groq, and Streamlit.

## Features
- Gmail management — read, send, search emails
- Calendar management — view and create events
- Expense tracking — log and read expenses via Google Sheets
- Web search via SerpAPI
- Notes and Tasks management

## Tech Stack
- **n8n** — agentic workflow orchestration
- **Groq** — LLM inference
- **Streamlit** — chat UI
- **Webhook** — connects frontend to n8n agent
